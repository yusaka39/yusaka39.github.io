プライバシーポリシー

Tasks が Google アカウントのデータをどう扱うかを説明します。最終更新日: 2026 年 11 月 18 日

アクセスするデータ

Tasks は、ログインした Google アカウントの Google Tasks にあるタスクリストとタスク (題名、メモ、期限、完了の状態) を読み書きします。ほかのデータにはアクセスしません。

使いみち

読み取ったデータは、アプリの画面とウィジェットに表示するため、そして利用者の操作をタスクに反映するためだけに使います。広告や分析には使いません。

保存する場所

  • ログインで得た認証情報 (アクセストークンとリフレッシュトークン) は、利用者の Mac の中にだけ保存します
  • タスクのデータは、利用者の Mac と Google のサーバーの間でだけやり取りします。開発者のサーバーはなく、開発者がデータを受け取ることはありません
  • ウィジェットは、通信できないときに表示するため、直近に読み取った今日のタスクを Mac の中に保存します
  • AI アシスタントが記録したタスクの提案は、Mac の中のデータベースに保存します

第三者への提供

Tasks がデータを第三者に送ることはありません。利用者が自分で MCP サーバーを AI アシスタントにつないだ場合に限り、そのアシスタントの求めに応じてタスクのデータを渡します。

削除とアクセスの取り消し

アプリでログアウトすると、保存した認証情報を削除し、Google に発行済みのトークンを失効させます。Google アカウントの設定からも、いつでもアクセスを取り消せます。

Google のポリシーへの準拠

Google API から受け取った情報の使用と他のアプリへの転送は、限定的な使用の要件を含め、Google API サービスのユーザーデータに関するポリシーに従います。

問い合わせ

このポリシーについての質問は、開発者の GitHub までお知らせください。
